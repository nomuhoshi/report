# 05 分光実験

実施：2026年10月13日・20日（2週で1本）、提出 10月26日

## 何をした実験か

ひとことで言えば **「光の波長をどうやって測るか」** を 3 段階でやる実験。

| | 内容 | 何がわかるか |
|---|---|---|
| **実験1** | 反射型回折格子でスクリーン上の輝線の位置を測る | Na・Hg・Cd の輝線の波長（**絶対測定**） |
| **実験2** | プリズムの最小偏角を測る | ガラスの屈折率とその波長依存（屈折率分散） |
| **実験3** | 回折格子を回しながらフォトダイオードで強度を測る | 分光器を作り、未知の光源（白色 LED）のスペクトルを得る |

実験3 はさらに 3 つに分かれる。

- **3-2** Cd ランプで波長を**校正**する（既知の波長 → 装置の目盛と波長の対応を決める）
- **3-3** 入射スリット幅を変えて**分解能**を測る
- **3-4** 校正した装置で**白色 LED** を測る ← 本番

### 実験1 と 実験3-2 の違い（混乱しやすい点）

| | 実験1 | 実験3-2 |
|---|---|---|
| 測り方 | 絶対測定 | 相対測定（校正） |
| 前提 | 格子定数 d が既知 | 波長が既知 |
| 得るもの | 波長の値そのもの | 「目盛 → 波長」の換算式 |

また、**x の意味が週で違う**。1週目の x はスクリーン上の輝線の位置 [mm]、2週目の x はマイクロメータの読み [0.01 mm]。

## 主な結果

**校正曲線**（x はマイクロメータの読み、1 目盛 = 0.01 mm）

```
λ = -5.201e-5 x^2 - 0.33303 x + 740.63   [nm]
```

Cd の 赤 643.847 / 緑 508.582 / 水色 479.992 nm の 3 点から最小二乗法で決定。

**検証**：校正に使っていない白色 LED のデータを換算すると、450.0 nm（LED チップ）と 580.2 nm（蛍光体）に山が出る。白色 LED として妥当な位置。

| 項目 | 値 |
|---|---|
| ガラスの屈折率 | 1.605〜1.656（波長が短いほど大きい） |
| 分解能（半値幅、スリット 0.1 mm） | 4.4 nm |
| 分解能（スリット 1 mm） | 11.6 nm |
| 白色 LED のピーク | 450.0 nm / 580.2 nm |
| LED 長波長側の半値幅 | 134 nm |

**分解能の実例**：Cd の 466.235 nm と 467.815 nm は間隔 1.58 nm しかなく、半値幅 4.4 nm より狭いため分離できず、1 つのピークにしか見えなかった。

## 講義の指示と実際の差（レポートに明記済み）

1. 実験3-2 は「全輝線を 3 回測って平均」の指示だが、実際は連続掃引（赤線のみ 2 回、他は 1 回）。データ点数が多く時間が足りなかったため。
2. 実験3-3 のスリット幅は「200〜1000 µm」の指示だが、実際は 100 µm と 1000 µm の 2 点のみ。
3. 実験3-4 の測定範囲は「350〜800 nm」の指示だが、実測は 424〜672 nm。
4. 課題2 は Na・Cd・Hg の輝線幅を問うが、実験3 で測ったのは Cd のみ。

## 未確定・注意

- スリット 1 mm の掃引は x = 605〜660 のみで、遠方の背景を測っていない。背景は両端の平均で代用したので、半値幅 11.6 nm には不確かさがある。
- Cd の赤線は実験1 で文献値の約半分（相対誤差 50.2 %）になった。原因は未確定。
