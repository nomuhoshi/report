## 1. 实验前的准备（阶段 A0・A）

### 阶段 A0：预习笔记（每次实验开始前）
**要求：** 实验开始前读讲义 PDF，写**两页**预习笔记，**手抄**，**中日双语**。

**怎么做**
1. 把讲义 PDF 发给 AI。**要让它看图页**，不能只读提取出来的文字（装置图、电路图、曲线图的含义文字里没有）。
2. 让 AI 按下面的模板写成一份文档：**左列日语、右列中文**的两列表，每行一个意思，短句。
3. 抄之前自己读一遍，读不懂的行问 AI，**自己讲得出来再抄**。

**篇幅与版式**
- 手写两页大约容纳**日中合计 2300 字**：第 1 页（原理）约 1100 字，第 2 页（实验）约 1250 字。写不下就删手顺里的细节，不要删原理和注意事项。
- 式子单独成行，保留讲义的编号。不用代码画示意图；需要图（装置、电路）的地方直接抄讲义里的图。

**内容模板**

| 页 | 写什么 |
|---|---|
| 第 1 页 原理 | 目的（一句）／现象与基本事实（讲义的结论逐条）／关键式与编号／怎么从测量值得到目标量（图线的斜率、截距各表示什么）／**要记住的式子和常数** |
| 第 2 页 实验 | 装置（一两行）／讲义里的数据表（数值自己重算）／手顺（按「准备 → 每次测量 → 收尾」）／**注意事项**（危险、不能碰的部件、要等多久）／数据处理与课题的方向／**疑问**（要问 TA 的） |

**规则**
- 只用讲义里有的内容，不编数值。
- **讲义里的数据表和常数，自己重算一遍核对。** 对不上的不要悄悄改，写进「疑问」，实验时问 TA。
- 课题只写思路和关键式（比如图线截距的含义），完整的论述留到写报告时自己写。
- 讲义说「自己查」的名称，写「要确认」，不要当成定论。
- 实验前不预测数据的数值。

### 阶段 A：写报告初稿
1. 把 `実験レポート執筆規範.md` 和本 SOP 发给 AI。
2. 发讲义 PDF。如果老师口头说过"某图不用写 / 某项目省略"，**当场告诉 AI**（本次老师口头说过讲义里有几张图可以省略）。
3. 让 AI 先回答三个问题，确认没有理解偏差：
   - 这个实验分几个子实验，各自测什么？
   - 讲义里的图号和报告里的图号怎么对应？（本次：报告图 1/2/3 ← 讲义图 6/7/5，符号也改了：x₀/x₁/θ、δ₀/x/α）
   - 哪些公式讲义里有？（只能用讲义里有的）
4. AI 只写没有数据的部分：1 目的、2 原理、3 実験の方法、7 結論，并为 4・5 章搭好小节标题。

### 红色 ★ 规则（重要）
**凡是需要你自己动手的地方，一律用红色粗体，并以 ★ 开头。**
原因：漏看一处就会被教授看到。手绘图的位置、待填的信息、待确认的值都算。
提交前在 Word 里 `Ctrl+F` 搜 `★`，**必须是 0 处**。

### 图
- 手绘图：照着讲义画，拍照插入。符号与讲义不一致的地方（上面的 x₀/x₁ 之类）在图里统一。
- 不会画 / 来不及画：让 AI 用 SVG 重画（保留 SVG 源文件，以后能改标注）。SVG 里用有衬线斜体表示变量。
- 图名在图下，表名在表上，编号按出现顺序连续。

## 2. 实验当天的记录清单（阶段 B）——最重要的一步

本次最大的遗憾都出在这里（背景没测、不记得狭缝宽、不记得 x 的含义）。**测的时候就按这张表记。**

**每个测量表的表头必须写：**
- [ ] 对应哪个子实验（如 3-2、3-4）
- [ ] 光源是什么
- [ ] x（或其他读数）的**单位**和**含义**——同一个字母两周的含义可能不同（本次：第 1 周 x 是屏幕上的位置 [mm]，第 2 周是千分尺读数 [0.01 mm]）
- [ ] 狭缝宽、距离 L、原点 x₀ 等**每次都可能变的设定值**
- [ ] 数值的**读法**：左端 / 中心 / 右端？只读了中心就写"只读中心"，并写原因（"左右不好读"）
- [ ] 用到的**仪器的识别编号**（实验室仪器上贴的 No.，如显微镜、电脑；**不是型号**）。老师希望写进 3 実験の方法

**必测项：**
- [ ] **背景值（没有信号时的读数）**——每组数据都要测，且在**离峰远的地方**测。本次 1 mm 狭缝那组没测，导致半値幅 11.6 nm 不确定。
- [ ] 峰附近加密测点（1 目盛一个），平坦处可以稀疏。
- [ ] 重复测量时标出哪几条重复了几次（本次只有红线测了 2 次）。

**与讲义不一致的做法，当场写下原因：**
- 本次：3 回平均 → 实际连续扫描；狭缝 200〜1000 µm → 实际 100 和 1000 µm；测量范围 350〜800 nm → 实际 424〜672 nm。
- 这些要在报告里**明写**，不要藏。老师看到"做不到所以这样"不会扣分，看到被藏的才有问题。

**记不清的怎么办：**
- 手稿上没有的，就当没有；**不要猜**。
- 报告里写"没有测量"或"没有记录"。

## 3. 数据理解会（阶段 D）

拿到手稿后，**不要直接建 Excel**。先让 AI 做三件事：

1. 把手稿每一页对应到子实验（谁是 3-2、3-3、3-4）。笔记上"绿""←""×"之类的标记也要问清楚（本次"绿"是目视色的标记，不是别的）。
2. 列出所有**不确定的值**，一条一条问你（温度、粘度、系数、x₀、L 等）。你回答，AI 不替你猜。
3. 写一页纸总结：这两周干了什么、每个子实验得到什么。**看懂了再往下做。**

> 本次的教训：我一开始看不懂数据。这一步让后面所有工作都顺了。

可以参考学长的报告（如果有），看他的结构、参考文献写法、测量点间隔。
**但他的报告里有别人的姓名和学籍番号，不要传到公开仓库。**

## 4. Excel（阶段 E）

### 结构
- 一个子实验一个工作表（`実験1_波長` / `実験2_屈折率` / `実験3-2_波長校正` …）。
- `説明` 工作表：每个表是干什么的、颜色含义。
- **`実験結果` 工作表：把报告的表 1〜表 N 一一对应地放进去**，用公式引用其他工作表。改了原始数据，报告里的表就能一起更新。
- 原始数据单独一个工作表，不改。

### 颜色
- 蓝字 = 手稿转录的输入值
- 黑字 = Excel 公式
- 绿 = 峰
- 黄 = **需要确认**（暂定值）

### 版面
- 表头：单位在同一行，不换行（`ピーク波長 [nm]`）。**列要宽到放得下一行**，否则换行的第二行会被固定行高切掉，贴到 Word 里就看不到单位。
- 不冻结窗格（会让滚动卡住）。
- 不要灰色底纹，用白色。
- 同一个数在 Excel、报告表、正文里**必须是同样的位数**。本次出过 134.3 / 134 不一致。
- 图表格式按规范第五节。

### 贴到 Word 之前
- Excel 里数字存成文字会出绿色小三角，**会被截进图里**。先关掉（`ignoredErrors`）或把格子改成数字。
- 复制表格成图片时，**选区往右、往下多包含一格空白**，否则右边和下边的边框会被裁掉。
- 贴完在 Word 里检查：边框完整、单位在、没有小三角。

## 5. 写 4 実験の結果 / 5 課題（阶段 F）

这一步的写法规则见规范第三节。补充几点实战经验：

### 公式只用讲义里有的
讲义里没有的推导，AI 不能自己加。要加就先问你。

### 半値幅的算法（本次用的）
1. 背景 I_b、峰值 I_p
2. 半值 I_h = I_b + (I_p − I_b)/2
3. 在峰两侧各找夹住 I_h 的两点，**线性内插**：x = x₁ + (I_h − I₁)/(I₂ − I₁)·(x₂ − x₁)
4. 先在 x 上量宽度，**再分别把左右两端换成波长后相减**（校正曲线是二次的，不能直接乘一个固定系数）
5. 峰是单点尖刺时，半値幅可能偏差很大——如实说，写"大约"。

### 校正曲线
用已知谱线（本次：Cd 红 / 绿 / 水色）解 λ = A x² + B x + C。**重叠的线不用来校正**（本次 Cd 蓝是 466.235 和 467.815 两条重叠，不用）。

### 文献值的出处要写清
本次来自讲义付录（理科年表）。若发现讲义里有笔误（Na D 线两个相同的值），报告里写明你用了什么替代。

### 文风：「学生水平」
- 句子短，一段 2〜3 句。
- 推测写「と思われる」「と考えられる」「可能性が考えられる」。
- **你自己解释不清的词不要用**（本次删掉了：分解能 → 先定义"能把靠得近的两条线分开的能力"；準位 → エネルギーの状態；蛍光体・半導体 → 不展开）。
  检验办法：老师问"这是什么意思"，你能不能一句话答出来？
- 每个论断要有你自己的数据支撑。没有数据的推测，用"かもしれない"，并且只写一次。
- 引用公式时核对编号（本次发现一处把"式(5)"写成了光栅公式，实际是式（1））。

### 物理量一律用行内数式
正文里的变量（n、δ₀、θᵢ、x₀、L、λ、A、B、C……）全部做成 Word 公式对象，外观与独立公式一致。
- 表达式合并成一个公式：`r = α/2`、`λ = Ax² + Bx + C`、`d(sinθₘ + sinθᵢ)`。
- **数值和单位保持普通文字**：`L = 150 mm` 只有 L 是公式，`= 150 mm` 是文字。
- 函数名 sin / cos / tan 用正体。

## 6. 6 考察、表紙（阶段 G・H）

### 6 考察：自己写，AI 只给素材
考察要回答："结果里有哪些不太对劲的地方，为什么？"
每一段**先写事实（你的数据），再写可能原因**，原因一律「可能性が考えられる」。
- 最简写法：2〜3 段，每段两句。
- 素材来自 4 和 5 里已经有的数据，不要凭空添。
- 原因你不知道的，就只写事实，**不写假原因**。

> 本次三段素材：① Cd 波长比 Na・Hg 偏差大（只读了一个位置）；② LED 两个峰的高度比不等于光强比（光栅效率、探测器灵敏度随波长变化）；③ 1 mm 那组背景没测。第 ③ 点（1 mm 那组背景没测）最后没放进考察，4.4 节里已经说明了。

### 表紙
- 模板：`物理学実験レポート表紙.docx`。
- 要填：第○回、題目、氏名、学籍番号、学部学科学年、共同実験者（名字一行、学籍番号一行，顺序对应）、提出年月日、実験実施日（两次实验日各一行）。
- 删掉模板最后一行「以下にレポート本文を記述してください。」
- **技术坑**：模板与正文的默认行距不同（正文是固定 15.2 pt），直接合并会把表紙的 18 pt 字切掉。每个表紙段落要显式设单倍行距，并且**表紙单独成节**（分节符，页边距独立）。
- 学籍番号、共同实験者是个人信息。**含表紙的版本不要传公开仓库。**

## 8. 与 AI 一起改文件的规则

这些是被坑出来的。

1. **改文件前，先把 Word / Excel 关掉。** 文件被占用时 AI 写不进去；更糟的是被占用时有些写入会"成功"但被覆盖。
2. **每次改之前，AI 必须先读你电脑上的最新版**，而不是用自己的脚本重新生成。你在 Word 里改过的东西（比如你自己贴的图片版表格、你自己填的学籍番号）会被覆盖。
3. **改完读回来核对**（对比文件大小或校验和，看内容）。写回失败不会报错的情况遇到过。
4. **Office 的"自动恢复"会把文件名改成 `(自動回復済み)`。** 先确认这是最新版，再作为基准。事后把名字改回正式的。
5. **不擅自删改你的内容。** 想改的地方先列出来问你。
6. **一次改一类。** 想把 20 处小修一起改时，先列清单让你确认。
7. **AI 的版面预览不可信**：它的预览软件缺字体、不能显示 Word 公式。公式、表紙、分页都要你在 Word 里亲眼确认。
8. 传到 GitHub 之前，先问哪些不能传（第 9 节）。

### 开场提示词（每个阶段）
- **阶段 A0**：「这是讲义 PDF（请看图，不只读文字）。按 SOP 阶段 A0 写两页中日双语预习笔记，左列日语、右列中文。讲义里的数据表请自己重算核对，不一致的写进疑问。」
- **阶段 A**：「这是实验 PDF 和规范。先回答：几个子实验？图号怎么对应？哪些公式讲义里有？再写第一阶段的部分。」
- **阶段 D**：「这是两周的手稿。逐页告诉我对应哪个子实验。不确定的值一条条问我，不要猜。然后写一页纸总结。」
- **阶段 F**：「按规范写 4 和 5。只用讲义里有的公式。不确定的地方写出来问我。」
- **阶段 G**：「给我考察的素材：结果里不对劲的地方，每条附数据出处。我自己写。」
- **阶段 I**：「按 SOP 第 7 节检查整篇。只列问题，不要改。」

| 生成脚本 | |
| README（实验做了什么、结果、与讲义的差异、未确认事项、考察素材） | |

仓库如果是公开的，上面右边那一列一律不传。想传就先改成私有。

每个实验一个文件夹 `0N_实验名/`，里面放：报告、Excel、`手稿/`、`図/`、`scripts/`、`README.md`。
README 里要有：这个实验做了什么、主要结果、**与讲义的差异**、**未确认的事项**、文献值来源、考察素材、残作业。

## 10. 踩过的坑（速查）

| 现象 | 原因 | 对策 |
|---|---|---|
| 表头单位在 Word 里看不到 | Excel 列太窄，换行后被固定行高切掉 | 列宽加宽到一行放得下 |
| 表右边、下边没有边框 | 复制成图片时选区把边缘裁掉了 | 选区多包含一格空白 |
| 表格右上角有绿色三角 | 数字存成文字 | 关闭错误提示，或改成数字 |
| 同一个数两种写法（134.3 / 134） | Excel 不同表的数字格式不同 | 数字格式统一，贴之前核对 |
| 段首出现小方块 / 白点（如「3」前面） | 用了"与下段同页"（keepNext），在显示编辑标记时会出现 | 不用，改成手动换页 |
| 段尾出现 ↵ | Word 的显示编辑标记，不会被打印 | `Ctrl+Shift+8` 关掉 |
| 标题前出现折叠三角 | 用了 Word 的标题样式 | 用正文样式 + 手动加粗 |
| 表紙的字被裁掉 | 正文默认行距是固定值 | 表紙每段显式设单倍行距 |
| 写回文件后内容是旧版 | 疑似同名暂存文件被缓存 | 换新文件名暂存再写回，读回核对 |
| 公式在预览里是空白 | 预览软件不支持 Word 公式 | 在 Word 里确认 |
| 1 mm 狭缝半値幅不可靠 | 没测背景 | **实验时测背景** |
| 红线偏差 50% | 左右两端读不到，只读了中心 | 记录读法；考察里只写事实，不编原因 |
| 讲义有笔误（Na 两个相同的值） | 讲义本身错 | 用理科年表的值，报告里说明 |
| 预习笔记手抄写不下 | 内容太细 | 两页约日中合计 2300 字；删手顺细节，保留原理和注意事项 |
| 讲义表里的数与自己算的不一致 | 讲义笔误或取值不同 | 预习时重算；不一致的写进疑问，实验时问 TA |
| 参考文献的章标题带了章号「8.」（被老师标为明显错误） | 把 8 章结构照搬，参考文献也编了号 | 参考文献不加章号；其余 7 章编号 |
| 结论只有平均值 | 想简洁 | 结论里同时写出各试料 / 各条件的值 |
| 写了型号，没写仪器编号 | 实验时没记 | 当天记录清单里加这一项 |
| 参考文献只列了一条，正文里没有编号 | 只在最后列了清单 | 正文用到的地方插入 [1]，写法照 p27 |

## 11. 收到批改后：怎么读、怎么录（阶段 K）

### 反馈 PDF 的读法
- **先看最后一页「指摘事項」**（文字评语）。
- 正文页上的**高亮颜色**有固定含义（最后一页底部有图例）：

| 颜色 | 含义 |
|---|---|
| 绿 | 图表编号、公式编号、参考文献编号（用得对的地方） |
| 黄 | 实验值、关键数值、实验里的小结、结论（得分点） |
| 红 | **明显错误** |
| 蓝 | 再提交的报告里改正了的部分 |

- 高亮本身没有文字，AI 读的方法：用 `pypdf` 读每页 `/Annots`（`/C` 是颜色、`/QuadPoints` 是位置），再用 `pdftotext -bbox` 取出该位置的字。
- 没有高亮、也没有最后一页评语的 PDF，就是**没批改的原稿**，别当成反馈。

### 老师提出过的通用要求（随批改增补）
| 要求 | 怎么做 | 放在哪一节 |
|---|---|---|
| 参考文献这一章**不加章号**（一般做法） | 标题写「参考文献」；其余 7 章编号 | 第 7 节清单、规范 |
| 实验方法要具体到能重现；**最好写仪器的识别编号** | 当天记下仪器上贴的 No.，3 実験の方法里写出 | 第 2 节、第 7 节清单 |
| 结论与目的对应，写具体的定量结果；**最好写出各试料（条件）各自求得的值** | 先列各自的值，再写平均 | 第 7 节清单 |
| 参考文献的写法照 1 年级《基礎物理学実験》p27；**正文里引用的地方插入文献编号** | 正文 [1] [2]；没引用的不列 | 第 7 节清单 |

措辞是「できれば……と良い」的是"最好写"，不是必须；「一般的である」「挿入すること」更明确，先改。

### 每次收到批改的处理
1. 读最后一页评语 + 高亮图例，按颜色分类（红先处理）。
2. 每条评语写成「指摘 → 对策 → 录入到 SOP 的哪一节」。
3. **只改老师提到的地方**，其余不动。
4. **只把通用的（对任何实验都成立的）录入 SOP**：加进第 7 节清单和第 10 节坑表，下次实验前就避开。只针对这一份报告的内容（某个实验的公式、数据、措辞）不进 SOP。

## 附：这套流程的原则

1. **不编。** 没测就写没测，没记录就写没记录。
2. **不替你猜。** 不确定的值先问。
3. **能自己解释才写。** 不能解释的词和结论不上报告。
4. **让要你动手的地方显眼。** 红色 ★。
5. **改完读回来。** 不信"写成功了"。
