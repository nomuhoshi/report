# 物理学実験レポート / 实验报告

東京理科大学 先進工学部 物理工学科の物理学実験レポートと、その作成規範をまとめたリポジトリ。

## これは何

- **実験は2週で1本**。1週目に測定の一部、2週目に残りを行い、レポートにまとめて提出する。
- レポートは **Word**、本文は **日本語**。
- AI（Claude など）に手伝わせる前提で、書き方の規範を `規範/` に置いてある。新しい実験を始めるときは、まずそれを読ませる。

## ディレクトリ

```
規範/
  実験レポート執筆規範.md     ← AI に最初に読ませるファイル
05_分光実験/
  README.md                  ← この実験で何をしたか
  5_分光実験_報告書.docx      ← 提出用レポート
  bunkou.xlsx                ← 計算とグラフ
  手稿/                      ← 実験中に取ったノート
  scripts/                   ← docx と xlsx の生成スクリプト
```

実験が増えたら `06_xxx実験/` のように同じ形で足していく。

## 使い方（次の実験のとき）

1. `規範/実験レポート執筆規範.md` を AI に読ませる
2. 実験の講義 PDF を渡す → 1週目の分（1 目的／2 原理／3 実験の方法／7 結論）を書かせる
3. 2週目の測定後、データと手稿を渡す → 4 実験の結果／5 課題 を書かせる
4. **6 考察は自分で書く**
5. グラフは Excel で作って Word に貼る。図名は図の下、表名は表の上

## 注意

- 数値・事実を AI に作らせない。測っていないものは「測定していない」と書く。
- 公式は講義に載っているものだけを使う。
- 温度・粘度・係数など不確かな値は、推測させずに必ず確認する。
